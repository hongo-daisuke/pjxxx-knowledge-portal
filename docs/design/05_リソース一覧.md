## 5. RAG (Bedrock) 関連

| リソース | 名称 | 管理 | 備考 |
|---|---|---|---|
| S3 Vectors ベクトルバケット | `pjxxx-{env}-001-knowledge-vectors` | 手順 | ベクトル専用バケットタイプ |
| S3 Vectors インデックス | `knowledge-index` | 手順 | 次元数 1024 (Titan Text Embeddings V2)、距離: cosine |
| Bedrock Knowledge Base | `pjxxx-{env}-001-knowledge-kb` | 手順 | ベクトルストア = S3 Vectors (**OpenSearch Serverless を選択しない**) |
| KB データソース | `pjxxx-{env}-001-knowledge-ds` | 手順 | ソース: DataBucket `documents/` プレフィックス。チャンク: 固定 512 トークン / オーバーラップ 15% |
| KB サービスロール | `pjxxx-{env}-001-knowledge-kb-role` | 手順 | DataBucket 読取 + ベクトルバケット読書 + 埋め込みモデル呼出 |
| 埋め込みモデル | Titan Text Embeddings V2 | — | モデルアクセス有効化が必要 |
| 生成モデル | Claude 系 (クロスリージョン推論プロファイル) | — | 利用リージョンの提供状況・モデル ID は構築時確認 |

## 8. コスト概算 (アイドル時月額・prd 単環境)

| リソース | 概算 | 備考 |
|---|---|---|
| S3 Vectors | 数円〜数十円 | ストレージ従量 (数千文書規模)。**常時課金なし** |

| Cognito (LITE) | 0 円〜 | 小規模 MAU |
| Bedrock (埋め込み/生成) | 利用量比例 | 同期・質問時のみ発生 |
| **合計 (アイドル時)** | **1,000 円未満目標** | OpenSearch Serverless 採用時の月額数万円と対比 |

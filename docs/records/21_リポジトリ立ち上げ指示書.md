## 手順 1: git 初期化前の確認

```bash
# プロジェクトルートで実施
git config --global core.precomposeunicode   # true であること (macOS 既定)。false/未設定なら true に設定
ls -la                                        # 構成確認 (frontend/ backend/ docs/ .github/ .claude/ 等)
```

- `.gitignore` の存在と内容を確認する。最低限: `node_modules/`, `dist/`, `.env`, `.env.*` (`!.env.example`), `__pycache__/`, `.venv/`, `.aws-sam/`, `.DS_Store`
- **コミットしてはいけないファイルの残存確認**: `.env` 実ファイル、`samconfig.toml` 内の実アカウント ID・実 ARN、`.claude/settings.local.json` 等の個人設定が無いか grep で確認する。あれば除外・プレースホルダ化してから初期化に進む

## 手順 2: git 初期化と初回コミット

```bash
git init -b main
git add -A
git status                    # 意図しないファイルが staged されていないか目視確認 (記録に貼る)
git commit -m "chore: initial commit (template + docs + Phase1 v3 implementation)"
```

## 手順 3: GitHub リポジトリ作成と push (⌨️ 一部手動)

```bash
gh auth status                # 未認証なら gh auth login (⌨️ 手動)
gh repo create <リポジトリ名> --private --source=. --push
```

- リポジトリ名は人間が決定する (例: `knowledge-portal`)。**private で作成する**
- `gh` が使えない場合は GitHub 画面でリポジトリ作成 → `git remote add origin ...` → `git push -u origin main` (⌨️ 手動)

## 手順 4: dev ブランチの作成

```bash
git switch -c dev && git push -u origin dev && git switch main
```

(Branch Protection / Environments / Secrets の設定は KNW-DOC-19 Stage B で実施するため、ここでは行わない)

## 手順 5: NFC 確定検証 (KNW-DOC-18 の「未検証」の消化)

```bash
git ls-files -z docs | python3 -c "
import sys, unicodedata
ns = sys.stdin.buffer.read().decode().split('\0')
bad = [n for n in ns if n and n != unicodedata.normalize('NFC', n)]
print(bad if bad else 'NFC OK')"
```

- `NFC OK` → KNW-DOC-18 残件 1 を確定クローズ (結果を KNW-DOC-22 に貼る)
- NFD が出た場合 → KNW-DOC-17 手順 3 の 2 段階 `git mv` で修正 → 再チェック → コミット

## 受入条件

1. `git log --oneline` に初回コミットが存在し、GitHub 上で main / dev の 2 ブランチが確認できる
2. リポジトリが private である
3. `git ls-files | grep -E "\.env$|\.env\.(dev|prod|development|production)|settings\.local"` がヒットしない (秘匿・個人ファイル未混入)
4. 手順 5 の出力が `NFC OK` (実出力を報告に貼る)
5. `git status` がクリーン
